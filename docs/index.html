Seu laboratório de contratos.

O Studio executa na memória deste navegador. Recarregar encerra a sessão; baixe os recibos para guardá-los. As chaves da sessão não são exportadas nem enviadas a um servidor. Os exemplos usam unidades de teste próprias do contrato. Este Studio não envia transações aos validadores VLOCK7SIN.
